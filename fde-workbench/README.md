# FDE Workbench｜独立公开网页版

本目录是基于通用项目业务规则与合成样例独立制作的自包含前端，不复制或导出任何禁止外部分享的工作台。一个 HTML 文件即可在现代浏览器运行，默认无网络模型请求或第三方资源依赖。

## 在线入口

GitHub Pages 路径 `fde-workbench/FDE-Workbench.html`，页内路由如下：

- `#home` 工作台
- `#fieldspec` 需求原文、缺失项、范围/验收审核及任务草稿
- `#loopops` 消息分类、人工去重、认领/结案/重开、日报和处理历史
- `#bridgecheck` JSON字段映射、精确十进制、错误行隔离、批准和导出

页内 hash 不需要服务器 SPA fallback，刷新不会请求不存在的子路径。原仓库首页没有修改，三个命令行私有仓库也保持私有。

## 实际使用与限制

- FieldSpec 默认只提取明确的9类标签，普通自然语言可手动复制原文引用分配字段。模型或人工建议不自动成为承诺，范围和验收需要审核。来源1–50个，输入2MB。
- LoopOps 默认只按求助/待办/进展/已知限制前缀分类，其他待确认；同项目合并key由人审核，无key只精确文本去重。关闭必须填写人工完成证据和理由，既有进展不自动关单。
- BridgeCheck 支持 JSON 对象数组和字段schema，最多10000记录/100目标字段；明确同名或alias映射，歧义保留空项；金额使用十进制整数运算并输出字符串，多余有效小数不静默舍入。错误行隔离，批准前可试跑，不写生产系统。
- TXT/MD/JSON 导入以工具支持范围为准。PDF、Office、CSV、音频不假解析；先转换为支持格式。
- 数据写入访问者当前浏览器 localStorage，支持JSON备份导入导出；同一浏览器可能被他人读取，清理浏览器会丢数据。导入审核需重新确认，未知版本/非法引用或状态被拒绝。
- 多标签页检测变更后阻止覆盖并提示先导出再刷新。支持 Web Locks 的浏览器使用锁协调写入；旧浏览器不可视为生产级并发存储。
- 可选模型仅使用用户自己的HTTPS Chat Completions端点和临时Key，用户必须明确开启并确认当前数据可外发；密钥只在内存、不导出、不持久化。受限工具最多8轮、每轮6调用；跨域、网络或协议不兼容如实停止，不使用假结果和代理。
- 不是企业IAM、服务端审计或不可篡改的证据系统；填写审核人只是本地人工流程记录。无群聊/CRM/ERP自动接入，不发送客户消息，不承诺排期、采购或效果。
