# woof-patrol

本仓库包含个人产品交互演示。以下三个演示保留原始 HTML 源码、在线演示链接与产品说明，不替换仓库原有首页及其他项目文件。

## TraceDesk｜企业知识助手

- **在线演示**：[打开 TraceDesk](https://bytedance.doubao.link/app/app_17j7ad92rue)
- **HTML 源码**：[TraceDesk.html](./TraceDesk.html)
- **产品重点**：演示来源原文、权限过滤、版本冲突与证据不足处理；支持编辑资料、记录反馈及导出证据报告，展示企业知识产品的可靠性边界。
- **可靠性边界**：资料为虚构样例，执行浏览器内确定性规则检索，不调用大模型，不连接真实企业知识库。模拟身份不等于生产级鉴权；资料编辑和反馈仅在当前页面会话生效。

## EvalLab｜Agent 评测与 Badcase 工作台

- **在线演示**：[打开 EvalLab](https://bytedance.doubao.link/app/app_17j79k82vyn)
- **HTML 源码**：[EvalLab.html](./EvalLab.html)
- **产品重点**：使用 8 条显式样例比较两版预置输出，支持阈值配置、逐项规则评分、人工复核及报告导出；区分质量、延迟与成本，评分不冒充模型实测。
- **可靠性边界**：答案、延迟和费用为预置样例；规则命中不等于语义正确，也不验证真实引用是否支持结论。8 条手工样例不能证明模型或策略的总体优势。

## GrowthLens｜商业化投放诊断助手

- **在线演示**：[打开 GrowthLens](https://bytedance.doubao.link/app/app_17j79w675qt)
- **HTML 源码**：[GrowthLens.html](./GrowthLens.html)
- **产品重点**：基于可编辑虚构数据计算 CTR、CVR、CPA 与 ROAS，展示指标变化、待验证归因假设和实验草案；建议带证据限制，不执行真实投放。
- **可靠性边界**：数据全部虚构，指标本地计算；诊断来自透明规则而非模型推理，归因仅为待验证假设。不连接平台账户、不调整预算、不承诺收益，也不输出统计显著性结论。

## 使用方式

1. 点击上述在线演示链接体验原发布版本。
2. 如需本地使用或修改，下载对应 `.html` 文件，用现代浏览器打开，再使用文本编辑器修改源码。
3. GitHub 的文件页面用于查看源码，不直接运行 HTML；请下载文件后打开，或自行部署到静态站点。
4. EvalLab 和 GrowthLens 通过 jsDelivr 加载 ECharts 5.6.0，图表需要网络连接；原文件包含图表加载失败时的文字提示。

## 演示声明

三个演示均为 AI 辅助制作的个人交互原型，不属于任何公司的正式生产系统，不代表真实模型测评、企业业务结果或广告投放效果。请勿输入公司机密、个人敏感信息、账户凭据或密钥。

本次归档保留原发布版本源码，仅将三个导出的入口文件分别命名为 `TraceDesk.html`、`EvalLab.html`、`GrowthLens.html`，未改变演示交互实现。
